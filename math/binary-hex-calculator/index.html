2Quick answer

A number can be written in any base: binary uses only 0 and 1, octal uses 0 to 7, decimal uses 0 to 9, and hexadecimal uses 0 to 9 and A to F. For example, 255 in decimal is 11111111 in binary, 377 in octal and FF in hexadecimal. Type a number above and pick its base.

3The formula

Every base is the same idea with a different set of digits. The value of a number is the sum of each digit times its base raised to its place:

Base conversion — in words: read the number in its own base to get its value, then divide that value by the new base again and again, writing down the remainders to build the new form. value = d0 × base^0 + d1 × base^1 + d2 × base^2 + …

Formula source: the standard place-value definition of number bases. No outside data is used — only the number and the base you type.

4Worked example: 255 in decimal

  1. Start with the number: 255 in decimal (base 10).
  2. To binary: divide by 2 again and again and write the remainders from last to first — 255 = 11111111 in binary.
  3. To octal: divide by 8 again and again — 255 = 377 in octal.
  4. To hexadecimal: divide by 16 again and again — 255 = FF in hexadecimal, because 15 is written as F.
  5. Answer: 255 in decimal = 11111111 in binary, 377 in octal, FF in hexadecimal.

Try it in the tool above: type 255, pick Decimal, and the result line shows all four forms.

6Questions about binary hex

What is binary, and where is it used?

Binary is base 2, using only the digits 0 and 1. It is the language of computers: every bit in a computer is a 0 or a 1. This calculator shows any number in binary, so you can see how a computer stores it.

What is hexadecimal, and why do the letters A to F appear?

Hexadecimal is base 16, so it needs 16 digits: 0 to 9, then A to F for the values 10 to 15. It is used for colours on the web, memory addresses and file codes, because one hex digit stands for exactly four binary digits.

What is octal?

Octal is base 8, using the digits 0 to 7. It was once common in computing, because one octal digit stands for exactly three binary digits. It is less used now, but this calculator still shows it.

Why does the calculator reject my number?

Because the digits must fit the base you picked. Binary allows only 0 and 1, so 102 is not a binary number. Octal allows only 0 to 7, and hexadecimal allows 0 to 9 and A to F. The calculator shows a clear message naming the digits that are allowed.

What is the limit on the size of the number?

Up to 64 digits, and the value must stay under 1,000,000,000,000. A longer number, or a value above that limit, shows a clear message instead of a result.

Is this calculator free, and do I need to sign up?

Yes, it is free, and no sign-up is needed. Nothing is uploaded: the calculation runs in your browser on your own device, and the numbers you type are not sent anywhere.
