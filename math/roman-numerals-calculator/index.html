2Quick answer

Roman numerals use the letters I, V, X, L, C, D and M for 1, 5, 10, 50, 100, 500 and 1,000. For example, 2026 in Roman numerals is MMXXVI, and XIV as a number is 14. Type a number from 1 to 3,999, or a Roman numeral, above.

3The formula

Roman numerals are built from seven letters, with a subtraction rule: IV is 4, not 6, because the I before the V means take 1 away from 5. The system covers 1 to 3,999:

Roman numerals — in words: build the numeral from the largest values down, using M, CM, D, CD, C, XC, L, XL, X, IX, V, IV and I; a smaller letter before a larger one means subtract it. I=1, V=5, X=10, L=50, C=100, D=500, M=1000

Formula source: the standard Roman numeral system, as used on clocks, book chapters and monuments. No outside data is used — only the number or numeral you type.

6Questions about roman numerals

How do Roman numerals work?

Seven letters stand for numbers: I is 1, V is 5, X is 10, L is 50, C is 100, D is 500 and M is 1,000. Letters are added together, except that a smaller letter before a larger one is subtracted: IV is 4, IX is 9, XL is 40 and CM is 900.

Why does this calculator stop at 3,999?

Because the standard system has no single letter above M (1,000), and 3,999 — MMMCMXCIX — is the largest number that can be written with the usual rules. Larger numbers need a bar over a letter, which is a different system, so the calculator shows a clear message above 3,999.

What is the smallest Roman numeral?

I, which is 1. There is no Roman numeral for zero, because the Romans had no symbol for it. A number below 1 shows a clear message.

Why is 4 written as IV and not IIII?

Because the subtraction rule is part of the standard system: a smaller letter before a larger one is taken away, so IV is 5 − 1 = 4. The calculator only accepts numerals written the standard way, and it says so plainly if a numeral is not written correctly.

Can I type lower-case Roman numerals?

Yes. The calculator reads lower-case letters the same as upper-case, so xiv works the same as XIV. The answer is always shown in upper-case.
