2Quick answer

To find percentage increase or decrease, subtract the old value from the new value, divide the difference by the old value, and multiply by 100. For example, from 80 to 100 the difference is 20, and 20 ÷ 80 × 100 = +25%, an increase. Type both values above and the change appears instantly below.

3The formula

Percentage change measures a difference against the value you started from, then scales it to hundredths. A positive result is an increase; a negative result is a decrease:

Percentage change — in words: subtract the old value from the new value, divide the difference by the old value, then multiply by 100. change % = ((new − old) ÷ old) × 100

Formula source: the standard arithmetic definition of percent (per hundred). No rate, price or outside data is used by this tool — only the two numbers you type.

4Worked example: 80 → 100

  1. Start with the two values: old 80, new 100.
  2. Find the difference: 100 − 80 = 20.
  3. Divide the difference by the old value: 20 ÷ 80 = 0.25.
  4. Multiply by 100: 0.25 × 100 = 25 — the result is positive, so it is an increase.
  5. Answer: from 80 to 100 is an increase of +25.00%.

6Questions about percentage increase/decrease

How do I work out percentage increase by hand?

Subtract the old value from the new value, divide the difference by the old value, then multiply by 100. From 80 to 100: the difference is 20, 20 ÷ 80 = 0.25, and 0.25 × 100 = +25% increase. This calculator does the same sum instantly.

How do I work out percentage decrease?

Use the same formula — the result simply comes out negative. From 100 down to 80: the difference is −20, −20 ÷ 100 = −0.20, and −0.20 × 100 = −20% decrease. The calculator shows the minus sign and the word “decrease” for you.

Why is going from 80 to 100 a 25% rise, but going back from 100 to 80 only a 20% fall?

Because the change is always measured against the value you start from. Going up, the difference of 20 is measured against 80, giving 25%. Coming back down, the same difference of 20 is measured against 100, giving 20%. The starting value is the base, so the two percentages differ.

What is the difference between percentage change and percentage points?

Percentage points is the plain difference between two percentages: 40% to 45% is a rise of 5 percentage points. Percentage change measures that rise against the starting value: 5 ÷ 40 × 100 = 12.50% increase. They are different numbers, so this page always labels which one it shows.

Can a decrease be more than 100%?

Not with ordinary positive values. Falling all the way to zero is a decrease of exactly 100%, and a value cannot fall below zero and stay a normal price, count or measurement. Increases have no such cap: a value that triples has risen by 200%.

What if the old value is zero?

The change cannot be worked out from a starting value of zero, because the formula divides by the old value and dividing by zero has no answer. The calculator shows a clear message instead of a made-up number. If something grew from nothing, describe it with the actual values rather than a percentage.
