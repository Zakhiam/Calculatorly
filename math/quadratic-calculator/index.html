2Quick answer

The roots of ax² + bx + c = 0 come from the quadratic formula: x equals minus b plus or minus the square root of b² minus 4ac, all divided by 2a. For example, x² − 5x + 6 = 0 has the roots x = 3.0000 and x = 2.0000. Type your own a, b and c above.

3The formula

The discriminant, b² − 4ac, decides what kind of answer there is: positive means two different real roots, zero means one repeated root, and negative means no real roots at all:

Quadratic formula — in words: the roots are minus b, plus or minus the square root of the discriminant (b squared minus 4ac), all divided by twice a. x = (−b ± √(b² − 4ac)) ÷ 2a

Formula source: the standard quadratic formula. No outside data is used — only the three numbers you type.

4Worked example: x² − 5x + 6 = 0

  1. Start with the equation: a = 1, b = −5, c = 6.
  2. Find the discriminant: b² − 4ac = (−5)² − 4 × 1 × 6 = 25 − 24 = 1.
  3. Take the square root of the discriminant: √1 = 1.
  4. Apply the formula: x = (5 ± 1) ÷ 2, so x = 6 ÷ 2 = 3 and x = 4 ÷ 2 = 2.
  5. Answer: the roots are x = 3.0000 and x = 2.0000.

Try it in the tool above: type 1, -5 and 6, and the result line shows x = 3.0000, x = 2.0000.

6Questions about quadratic

What is a root of a quadratic equation?

A root is a value of x that makes the equation true — the value where the curve crosses the x-axis. For x² − 5x + 6 = 0, the roots are 3 and 2, because 3² − 5 × 3 + 6 = 0 and 2² − 5 × 2 + 6 = 0.

What does it mean when there are no real roots?

It means the discriminant is negative, so its square root is not a real number, and the curve never crosses the x-axis. For example, x² + 1 = 0 has a discriminant of −4, so the calculator says plainly that there are no real roots, instead of giving a made-up number.

What is a repeated root?

It happens when the discriminant is exactly zero: the plus and minus parts of the formula give the same value, so there is one root counted twice. For example, x² + 2x + 1 = 0 has the repeated root x = −1.0000.

What if a is zero?

Then it is not a quadratic equation at all — it is a straight-line equation, bx + c = 0, with one root. The calculator shows a clear message and asks for a value of a that is not zero, instead of dividing by zero.

How do I check the roots by hand?

Put each root back into the equation: the result must be zero. For x = 3 in x² − 5x + 6 = 0: 9 − 15 + 6 = 0. For x = 2: 4 − 10 + 6 = 0. Both check out.
