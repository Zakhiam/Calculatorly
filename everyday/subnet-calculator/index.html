2Quick answer

A subnet splits an IPv4 address into a network part and a host part, using the prefix length. The address 192.168.1.10 with a /24 prefix sits on the network 192.168.1.0, with broadcast 192.168.1.255 and 254 usable hosts. Type an address and a prefix above to work out your subnet.

3The formula

The subnet mask has 1 bits for the prefix length and 0 bits after it. A /24 mask is 255.255.255.0. The usable hosts are the addresses between the network and the broadcast address.

Network address — in words: take the address and the subnet mask made from the prefix, and keep only the bits where both have a 1. network = address AND subnet mask; broadcast = network OR (NOT subnet mask)

Formula source: IPv4 bitwise arithmetic on the address and prefix you type. This page covers IPv4 only, in dotted form such as 192.168.1.10.

4Worked example: 192.168.1.10/24

  1. Subnet mask for /24: 255.255.255.0.
  2. Network: 192.168.1.10 AND 255.255.255.0 = 192.168.1.0.
  3. Broadcast: 192.168.1.0 OR 0.0.0.255 = 192.168.1.255. Usable hosts: 256 − 2 = 254.
  4. Answer: 192.168.1.0/24.

Try it in the tool above: type 192.168.1.10 and 24, and the result line shows 192.168.1.0/24.

6Questions about subnet

Why are there 254 usable hosts in a /24, not 256?

Because two addresses are set aside: the network address itself (192.168.1.0) and the broadcast address (192.168.1.255). The 254 addresses between them, from 192.168.1.1 to 192.168.1.254, can be given to devices.

What does the prefix length mean?

It is the number of bits in the network part of the address. A /24 keeps the first 24 bits as the network and leaves 8 bits for hosts, which is 256 addresses. A /16 leaves 16 bits for hosts, or 65,536 addresses.

What is the first and last usable address?

The first is the network address plus 1, and the last is the broadcast address minus 1. In a /24 starting at 192.168.1.0, they are 192.168.1.1 and 192.168.1.254. The table under your result shows both.

Does this work for IPv6?

No. This page covers IPv4 only, in dotted form such as 192.168.1.10. IPv6 addresses use a different form and are not accepted here.

What if I type an address that is not valid?

The page shows a message instead of a result. Each of the four parts must be a whole number from 0 to 255, and the prefix must be from 0 to 32.

Is this calculator free, and do I need to sign up?

Yes, it is free, and no sign-up is needed. Nothing is uploaded: the calculation runs in your browser on your own device, and the address you type is not sent anywhere.
